OUR LEARNING PROGRAMS

Two Programs. One Destination.

Explore our programs and choose the path that fits your passion and goals.

Data Analytics

Turn raw numbers into real decisions.

The Data Analytics program introduces learners to the complete practical workflow of a data analyst from receiving messy raw data to delivering clear, business-focused insights. Every skill is taught through doing, not watching..

WHAT YOU'LL LEARN
Spreadsheet Analysis

Master spreadsheets for data manipulation, pivot tables, and building structured reports that any business team can act on.

Data Cleaning

Learn how to identify errors, remove unnecessary data, and prepare datasets for accurate analysis.

SQL

Write queries to extract, filter, and aggregate exactly the data you need from relational databases

Data Visualization

Learn how to turn data into clear charts and visual presentations that make insights easier to understand.

Business-focused Analysis

Apply analytical thinking to real business problems. Learn to frame questions, interpret results, and make recommendations.

Program Outcome:

Graduate with multiple deployed websites in your portfolio that you can show any potential employer or client.

Web Development

Design and build websites that work.

The Web Development program walks learners through the complete process of building websites from writing the first line of HTML to deploying a finished project on the internet. You'll leave with real projects, not just course certificates.

WHAT YOU'LL LEARN
HTML5

Structure web pages with semantic HTML5 and create accessible, well-organized web pages.

CSS

Style and design responsive websites using layouts, colors, typography, and modern CSS.

JavaScript

Add interactivity, logic, and dynamic behavior to your websites. JavaScript is what transforms a static page into a real application.

Git & GitHub

Track changes, collaborate with others on projects, and manage your code using Git and Github.

Building Web Projects

Apply your skills by creating practical websites and projects that demonstrate your development abilities.

Program Outcome:

Graduate with a portfolio of real analyses, dashboards, and reports that demonstrate you can extract meaning from data.
