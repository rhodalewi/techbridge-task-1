Your Internship Roadmap

Explore each task, see when it happens, and understand what you'll build.

Phase 1 ─ Days 1-8

01
DAY 1

Build the TechBridge Homepage

Create the first version of the TechBridge website using HTML and CSS.

Beginner
View details 🠆

You'll build a complete homepage for the TechBridge platform, introducing the organisation, communicating its programs, and giving visitors a clear call to action. This task focuses on structure, layout, and fundamental web design principles.

Skills Practiced
HTML CSS
02
DAY 2

Build the TechBridge Programs Experience

Create a Programs experience that presents TechBridge's available learning programs.

Beginner
View details 🠆

Extend the website by designing a dedicated Programs section. You'll present both programs clearly, Data Analytics and Web Development with enough information for a visitor to understand what they would learn and how to apply. Focus on information hierarchy and readability.

Skills Practiced
HTML CSS
03
DAY 3

Build the Internship Tasks Experience

Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

Beginner → Intermediate
View details 🠆

Design an interface that maps out the entire 30-day internship. Visitors including prospective interns should be able to understand all 8 tasks, the day each task starts, and how the internship progresses from beginner to advanced work. You are building this page right now.

Skills Practiced
HTML CSS

Phase 2 ─ Days 11-19

04
DAY 4

Build an Interactive Task Tracker

Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

Intermediate
View details 🠆

Take your Task 3 interface and bring it to life with JavaScript. Interns should be able to mark tasks as complete, see their overall progress, and get a dynamic visual sense of where they are in the 30-day journey. Your first taste of real interactivity.

Skills Practiced
HTML CSS JavaScript
05
DAY 5

Build the Intern Registration Experience

Create a professional registration and onboarding interface for TechBridge interns.

Intermediate
View details 🠆

Design and build the form and onboarding flow that a new intern completes when joining TechBridge. This includes form validation, clear UX feedback, and a polished, professional feel that reflects the credibility of the programme. Forms are a core part of every web platform.

Skills Practiced
HTML CSS JavaScript
06
DAY 6

Build the Task Submission System

Create an interface through which interns can prepare and submit their task work.

Intermediate → Advanced Beginner
View details 🠆

Build the submission experience that interns use to deliver their work at the end of each task. This includes an interface for uploading or linking submissions, writing task notes, and confirming delivery. You'll need to think carefully about states which are empty, in-progress, and submitted.

Skills Practiced
HTML CSS JavaScript

Phase 3 ─ Days 22-26

07
DAY 7

Build the Intern Dashboard

Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

Intermediate → Advanced Beginner
View details 🠆

Design a centralised dashboard experience — the intern's home base on the platform. It should surface their profile, show task progress at a glance, list recent submissions, and give them quick access to what's coming next. Dashboards require careful thinking about hierarchy and information density.

Skills Practiced
HTML CSS JavaScript
08
DAY 8

Build the Complete TechBridge Internship Platform

Combine the different components created during the internship into a complete TechBridge platform.

Advanced Beginner
View details 🠆

The capstone. You bring together everything you've built across Tasks 1–7 into a single, cohesive, fully navigable platform. This is your portfolio piece — the proof of what 30 days of focused, practical work can produce. Consistency, navigation, and polish are the focus.

Skills Practiced
HTML CSS JavaScript
